# Quaderni dei rilievi

Qui gli agenti di controllo scrivono ciò che trovano **mentre
lavorano**. Non è un piano: il lavoro si segue sulle issue. Un rilievo
confermato diventa una issue e nella riga va il suo numero. Le righe
risolte da più di un giro si tolgono (restano nella storia di git).

| Quaderno | Chi lo scrive |
|---|---|
| `bug.md` | `cacciatore-bug` |
| `revisione.md` | `revisore-capo` |
| `ottimizzazione.md` | `ottimizzatore` |
| `limiti-api.md` | `guardiano-limiti` |
| `aggiornamenti.md` | `sentinella-aggiornamenti` |
| `fornitori-ai.md` | `custode-ai` |

Colonne comuni: data · dove (`file:riga`) · cosa · gravità · stato
(`aperto`, `issue #N`, `risolto <commit>`).
